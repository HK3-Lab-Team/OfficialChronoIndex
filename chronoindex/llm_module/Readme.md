## LLM Module – Access & Usage

The ChronoIndex LLM module enables the integration of nutritional and behavioral data into LLM-driven downstream pipelines through structured generation. This includes tasks such as standardized food annotation, semantic enrichment, and transformation of free-text inputs into structured representations compatible with longitudinal analysis workflows.

Access to this module is subject to usage quotas and may require additional configuration depending on the scale and scope of the project.
